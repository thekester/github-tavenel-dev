# CSS shorts: source code

275 demos, one folder each: `index.html` (markup) + `style.css`. No JavaScript: every interaction uses :hover, :focus, checkboxes/radios with labels, and :has().

Open `index.html` at the root to browse them all, or open any `<slug>/index.html` directly in a recent Chromium-based browser (some demos use @property, :has(), offset-path, linear(), mask-composite).

In the videos the cursor clicks labels, hovers zones, or types into inputs: do the same in the browser to replay each effect.
