# A memory game in pure CSS

3D flips + :has() pair detection

[Watch on YouTube](https://www.youtube.com/shorts/0gTl5kfLKqQ)

## Try it

Open [index.html](index.html) in a recent browser, or [open the live demo](https://thekester.github.io/github-tavenel-dev/videos/css/memory-game/).
Hover, click, focus, or type into the demo to explore its interactions.

## Files

- `index.html`: markup and controls.
- `style.css`: styling, animations, and interactions.

No install or build step is needed. Some examples use recent CSS features; a current Chromium-based browser is recommended.
